# Проектная работа: Вёрстка сайта-кастомизатора
    Хочется посмотреть, как будет выглядеть сайт в разных цветах? Добро пожаловать.

## Стек технологий
**_HTML5_**, **_CSS3_**, **_JavaScript_**, *React*, *Webpack*

## Немного о настройке проекта

[Макет проекта](https://www.figma.com/file/FEeiiGLOsE7ktXbPpBxYoD/Custom-dropdown?type=design&node-id=0%3A1&mode=design&t=eXRJnWC6Xsuw0qR4-1)

Для запуска приложения:
- Сначала подтянуть необходимые библиотеки `npm ci`.
- Далее для запуска приложения выполнить команду `npm run start`.
- Если необходимо получить бандл, выполнить `npm run build`.

Для запуска Storybook выполнить `npm run storybook`.

Для запуска линтера для стилей выполнить `npm run stylelint`.

Для запуска линтера выполнить `npm run lint`

Для запуска форматтера выполнить `npm run format`

### Особенности проекта (что сделано)
- Выполнена верстка сайта по макету.
- Создана интерактивность:
    - Открывающиеся и закрывающиеся элементы на странице.
    - Динамическое изменение стилей страницы.
    - Хранение состояния страницы в плане стилей для возможности вернуть их по нажатию кнопки.
    - Создана интерактивная форма с сохранением состояния.
- Настроена передача данных между формой и страницей.
